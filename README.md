# Astral — rebuilt studio website

A static, multi-page website for Astral, focused on custom Discord bot development, automation, moderation and community systems.

## Structure
- `index.html` — home
- `services.html` — services overview
- `solutions.html` — solution library
- `custom-bots.html` — custom bot development
- `automation.html` — automation and integrations
- `moderation.html` — moderation systems
- `community.html` — community systems
- `features.html` — feature library
- `hosting.html` — hosting and maintenance
- `work.html` — selected/representative work
- `process.html` — project process
- `pricing.html` — pricing ranges
- `ideas.html` — bot ideas
- `demo.html` — interaction concept
- `about.html` — studio philosophy
- `faq.html` — frequently asked questions
- `contact.html` — project enquiry
- `privacy.html` — privacy notice
- `terms.html` — general terms
- `404.html` — not found page

## Design
The previous dark/purple interface has been replaced with a warm editorial system: paper tones, charcoal typography, orange accents, green utility panels, oversized headings, restrained borders and product-style cards.

## Deploy
This is still plain static HTML/CSS/JavaScript. There is no build step and no framework requirement.
